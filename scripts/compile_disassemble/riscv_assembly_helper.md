# RISC-V Instruction Recap for `inferenceTPG`

## 🧱 Stack / Function Setup

| Instruction | Meaning | What it does |
|-------------|---------|--------------|
| `addi sp, sp, -80` | Add Immediate | Allocates 80 bytes on the stack |
| `sw reg, offset(sp)` | Store Word | Saves register to stack |
| `lw reg, offset(sp)` | Load Word | Loads register from stack |
| `ret` | Return | Returns to caller (`jr ra`) |
| `jr reg` | Jump Register | Jump to address in register |
| `jal target` | Jump and Link | Calls function, stores return address in `ra` |

## 🔁 Control Flow / Branching

| Instruction | Meaning | Condition |
|-------------|---------|-----------|
| `beqz rs, target` | Branch if Equal to Zero | if `rs == 0` |
| `bnez rs, target` | Branch if Not Zero | if `rs != 0` |
| `blt rs1, rs2, target` | Branch if Less Than | signed comparison |
| `bltu rs1, rs2, target` | Branch if Less Than Unsigned | unsigned comparison |
| `bge rs1, rs2, target` | Branch if Greater/Equal | signed |
| `blez rs, target` | Branch if ≤ 0 | signed |
| `j target` | Jump | Unconditional jump |

## ➕ Arithmetic Instructions

| Instruction | Meaning | What it does |
|-------------|---------|--------------|
| `add rd, rs1, rs2` | Add | `rd = rs1 + rs2` |
| `sub rd, rs1, rs2` | Subtract | `rd = rs1 - rs2` |
| `addi rd, rs1, imm` | Add Immediate | `rd = rs1 + imm` |
| `neg rd, rs` | Negate (pseudo) | `rd = -rs` |
| `li rd, imm` | Load Immediate (pseudo) | Loads constant |
| `lui rd, imm` | Load Upper Immediate | Loads upper 20 bits |

## 🧮 Bitwise / Shift Operations

| Instruction | Meaning | What it does |
|-------------|---------|--------------|
| `slli rd, rs, imm` | Shift Left Logical | `rd = rs << imm` |
| `sll rd, rs1, rs2` | Shift Left Logical | Shift by register value |
| `srai rd, rs, imm` | Shift Right Arithmetic | Sign-preserving right shift |
| `and rd, rs1, rs2` | Bitwise AND | `rd = rs1 & rs2` |
| `not rd, rs` | Bitwise NOT (pseudo) | `rd = ~rs` |

## 🔍 Comparison Instructions

| Instruction | Meaning | Result |
|-------------|---------|--------|
| `slt rd, rs1, rs2` | Set Less Than | `rd = 1 if rs1 < rs2 else 0` |
| `slti rd, rs, imm` | Set Less Than Immediate | Compare with constant |
| `seqz rd, rs` | Set if Equal Zero (pseudo) | `rd = (rs == 0)` |

## 📦 Memory Access

| Instruction | Meaning | What it does |
|-------------|---------|--------------|
| `lw rd, offset(base)` | Load Word | Load 32-bit value from memory |
| `sw rs, offset(base)` | Store Word | Store 32-bit value to memory |

> Example: `lw a4,-1708(gp)` loads from a global variable using the global pointer `gp`.

## 🧠 Special Function Call

`jal 4966 <__clzsi2>` calls `__clzsi2`, which is:

- A compiler runtime helper  
- Performs Count Leading Zeros (CLZ) on a 32-bit integer  
- Often generated by GCC when the CPU lacks native `clz` instruction  

## 🧩 Pseudo-Instructions Used

| Pseudo | Expands To |
|--------|------------|
| `li` | `addi` or `lui + addi` |
| `mv rd, rs` | `addi rd, rs, 0` |
| `neg rd, rs` | `sub rd, x0, rs` |
| `not rd, rs` | `xori rd, rs, -1` |
| `ret` | `jalr x0, 0(ra)` |
| `j target` | `jal x0, target` |
